A divisão de papéis

O HTML cuida do significado: isto é um cabeçalho, isto é uma tabela de médicos. O CSS cuida da apresentação: esta cor, esta fonte, este espaçamento. Misturar os dois é o que torna um site caro de manter.

O que é CSS e as três formas de aplicá-lo [1]

CSS, de Cascading Style Sheets, é a linguagem que descreve como o documento HTML deve ser apresentado. A mesma marcação da Clínica Vida+ pode ganhar dez aparências diferentes sem que uma tag seja tocada.

1. Inline, no atributo

Um style dentro da própria tag. Vale só para aquele elemento, repete em cada tag e vence quase toda disputa de especificidade, o que esconde bugs.

2. Interno, no head

Um bloco style dentro do documento. Serve para um teste rápido, mas não alcança as outras páginas do site.

3. Externo, em arquivo

Um arquivo .css ligado por link. Uma folha para o site inteiro, guardada em cache pelo navegador. É o que usamos sempre.

<!-- dentro do <head> do index.html da Clínica Vida+ -->
<link rel="stylesheet" href="assets/css/site.css">
Takeaway

Sempre externo. Quando o azul da clínica mudar, você quer editar um arquivo, não 40 atributos style espalhados por seis páginas.

Anatomia de uma regra CSS [1]

Toda folha de estilos é uma sequência de regras, e toda regra tem sempre as mesmas quatro partes.

Comentário em CSS é /* assim */, e só assim. O // de outras linguagens não existe aqui: o navegador descarta a linha inteira em silêncio, e você fica caçando um estilo que nunca chegou a ser aplicado.

Os cinco seletores que resolvem o dia a dia

SeletorComo se escreveCasa com, na página da clínica
Tipoh2Todos os h2 da página, sem exceção.
Classe.card-especialidadeTodo elemento com class="card-especialidade". Repetível, e é o seletor do dia a dia.
Identificador#agendamentoO único elemento com id="agendamento". Um id não se repete na página.

Cascata, especificidade e herança [2]

Quando duas regras disputam o mesmo elemento, o navegador decide em três etapas, nesta ordem: 1) origem e importância, 2) especificidade e, só em caso de empate, 3) ordem de escrita, em que a última vence.

Nível de especificidadeExemploPesoVence quem
Estilo inlinestyle="color: red"1 - 0 - 0 - 0Compara-se da esquerda para a direita. Um único ponto numa coluna mais à esquerda derruba qualquer quantidade de pontos à direita.
Identificador#agendamento0 - 1 - 0 - 0
Classe, atributo ou pseudo-classe.card-especialidade0 - 0 - 1 - 0
Tipo ou pseudo-elementonav, a0 - 0 - 0 - 1

Herança: propriedades de texto, como color, font-family e line-height, passam do pai para os filhos. Propriedades de caixa, como padding, border e margin, não passam. Por isso a tipografia do site inteiro se declara uma vez, no body.

Exercício, 5 minutos: qual cor prevalece?

No menu da Clínica Vida+ existe este link:
<nav class="menu"><a class="menu-link" href="#agendamento">Agendar consulta</a></nav>

A folha de estilos tem as três regras abaixo, nesta ordem. De que cor sai o texto do link, e por quê?

a          { color: #1F2A30; }   /* 1 seletor de tipo             ->  0 - 0 - 0 - 1 */
nav a      { color: #0B6E75; }   /* 2 seletores de tipo           ->  0 - 0 - 0 - 2 */
.menu-link { color: #2E9E7E; }   /* 1 seletor de classe           ->  0 - 0 - 1 - 0 */
Resposta

Verde #2E9E7E, da regra .menu-link. Uma classe pesa mais do que qualquer quantidade de seletores de tipo, então 0-0-1-0 derruba 0-0-0-2. E não é por ser a última linha: a ordem só desempata quando a especificidade é idêntica.

Acrescente #agendamento a { color: #E4572E; } e o laranja passa na frente das três, porque o identificador está numa coluna mais à esquerda. Já !important atropela tudo isso e por isso é o último recurso, não o primeiro.

Cores, tipografia e unidades

Cores

  • #0B6E75: hexadecimal, dois dígitos para vermelho, verde e azul.
  • rgb(11 110 117): os mesmos canais em decimal, de 0 a 255.
  • rgb(11 110 117 / 60%): o quarto valor é a opacidade.

Tipografia

  • font-family aceita uma lista de alternativas, da preferida à genérica.
  • font-size define o corpo; font-weight vai de 100 a 900.
  • line-height: 1.6, sem unidade, é 1,6 vez o corpo do próprio elemento.
UnidadeO que ela medeExemplo
pxPixel, valor absoluto e fixo.border: 2px
remMúltiplo do corpo da raiz, o html, que é 16px por padrão.1.5rem = 24px
emMúltiplo do corpo do próprio elemento, e acumula no aninhamento.padding: 0.5em
%Porcentagem da medida correspondente do elemento pai.width: 100%

A paleta da Clínica Vida+ em variáveis CSS

Uma variável é declarada uma vez em :root, que é o próprio html, e lida com var() em qualquer regra da folha. É a diferença entre trocar a cor da clínica em um lugar ou em oitenta.

:root {
  --vida-primaria:   #0B6E75;   /* verde-azulado do logotipo   */
  --vida-secundaria: #2E9E7E;   /* confirmação de agendamento  */
  --vida-destaque:   #E4572E;   /* chamada para ação           */
  --vida-fundo:      #F4F7F6;
  --vida-texto:      #1F2A30;
}

header { background-color: var(--vida-primaria); color: #FFFFFF; }

Takeaway

width não é a largura da caixa: é a largura do conteúdo. Somar padding e borda é responsabilidade sua, até você mudar essa conta com box-sizing.

Exercício, 5 minutos: a mesma caixa com border-box [3]

A caixa é a mesma dos dois lados: width: 300px, padding: 20px e border: 2px. Só muda quem manda no width.

* { box-sizing: border-box; }   /* a primeira regra de qualquer folha de estilos deste semestre */
04 Exercício, largura da caixa
13

Como as caixas se comportam: display

Antes de arrumar as caixas na tela, é preciso saber como cada uma se comporta sozinha. É o display que decide isso, e cada tag já vem com um valor padrão.

ValorTags que já usamOcupa a linha inteira?Aceita width e height?
blockdiv, p, section, h1Sim, e empurra o próximo para baixo.Sim, mais padding e margem nos quatro lados.
inlinea, span, strongNão, fica na mesma linha do texto.Não. Margem e padding verticais não empurram nada.
inline-blocknenhuma por padrãoNão, mas convive lado a lado.Sim. É o meio-termo dos dois.

Colapso de margens: quando a margem de baixo de um elemento encosta na margem de cima do seguinte, as duas não somam: vale a maior. Se a seção de apresentação tem margin-bottom: 24px e a de especialidades tem margin-top: 32px, o espaço entre elas é de 32px, não de 56px. O colapso é vertical, só acontece entre elementos block, e não acontece com padding.

Flexbox: um contêiner e dois eixos [4]

Takeaway

Flexbox é alinhamento em uma dimensão. Você declara o comportamento no contêiner, uma vez, e ele vale para todos os itens, quantos forem.

Takeaway

04 Flexbox, justify-content e align-items

Na prática: a lista de especialidades vira uma fileira de cards

O ul da Aula 03 continua sendo uma lista, porque é isso que ele é. O que muda é só a apresentação: acrescente a ele a classe lista-especialidades e escreva as duas regras abaixo.

.lista-especialidades {        /* o contêiner: decide o arranjo do conjunto */
  display: flex;
  flex-wrap: wrap;             /* deixa a fileira quebrar em tela estreita  */
  gap: 20px;                   /* espaço entre os cards, sem margem        */
  justify-content: center;     /* centraliza a fileira no eixo principal   */
  list-style: none;   padding: 0;
}
.lista-especialidades li {     /* o item: decide a própria caixa           */
  width: 260px;
  padding: 20px;
  background-color: #FFFFFF;
  border-left: 4px solid var(--vida-secundaria);
  border-radius: 8px;
}

O contêiner cuida do arranjo do conjunto, o item cuida da própria caixa. Confundir os dois é a fonte da maioria dos "meu Flexbox não funciona".

04 Flexbox na prática
17

Quiz de fixação

No box model padrão do CSS, sem border-box, o que a propriedade width define?
  • A A largura total do elemento, já somando a área de conteúdo, o padding e a borda declarada.
  • B A largura da margem externa, que é o espaço reservado entre o elemento e os seus vizinhos na página.
  • C A largura da janela do navegador, da qual o elemento passa a ocupar uma fração proporcional.
  • D Apenas a largura da área de conteúdo, sem contar o padding nem a borda, que são somados depois.

Laboratório, passo 4 de 5: as especialidades viram cards

A partir daqui você trabalha sozinho, com o professor circulando pela sala. Acrescente class="lista-especialidades" ao ul das especialidades e escreva as regras do slide 17.

O que precisa acontecer na tela

  1. As especialidades ficam lado a lado, em cards de largura igual, sem marcador de lista.
  2. Existe um espaço regular entre os cards, criado por gap e não por margem.
  3. Todos os cards terminam na mesma altura, mesmo com textos de tamanhos diferentes.
  4. Ao estreitar a janela, a fileira quebra em uma segunda linha, por causa do flex-wrap.

Abra o inspetor do navegador, selecione um card e olhe o diagrama do box model no painel lateral. Ele mostra, em números, o conteúdo, o padding, a borda e a margem daquela caixa. É a figura do slide 12, calculada ao vivo pelo navegador.

Entregável de hoje e prévia da Aula 05

Abra lado a lado, no projetor, a página que você entregou na Aula 03 e a de hoje. O HTML é praticamente o mesmo arquivo: tudo o que mudou coube em uma folha de estilos.

  • Commitado e enviado na branch feature/estilo-inicial.

Prévia da Aula 05

  • CSS Grid e layout que se adapta à largura da tela, na abordagem mobile first.
  • O formulário de agendamento da clínica, com os tipos de campo certos e validação nativa.
As três ideias da semana

Quando duas regras brigam, quem decide é a especificidade, não a ordem; width mede só o conteúdo, até border-box mudar a conta; e no Flexbox o contêiner arruma o conjunto enquanto o item cuida da própria caixa.
